# Controle de Contas - Mensal e Anual

Sistema completo para controle de vencimentos.

## Funcionalidades
- Visao mes a mes e anual
- Calendario visual
- Contas fixa, parcelada e unica
- PIX copia e cola
- Comprovantes por mes
- Excel do mes e anual
- Avisos reais: notificacao do navegador, e-mail e push via ntfy.sh
- PWA - instala no celular

## Como usar
